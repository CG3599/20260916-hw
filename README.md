# 個人形象專屬網站 (Personal Portfolio)

現代極致美學風格的個人形象網站，具備深色毛玻璃（Dark Glassmorphism）、動態光暈、姓名即時自訂與響應式排版。

## ✨ 特色亮點

- **線上即時更名與自訂**：點擊大標題或右上角按鈕即可自訂姓名、頭銜、Email 與個人簡介，資料自動存於 LocalStorage。
- **現代視覺設計**：深色調底色搭配環境光暈、滑鼠游標跟隨微光、細緻玻璃質感。
- **動態微互動**：打字機輪播專業標語、卡片 3D 懸浮、一鍵複製聯絡資訊。
- **純前端零依賴**：基於純 HTML5、CSS3 與原生 JavaScript，無需繁瑣建置流程，隨開即用。

## 🌐 透過 GitHub Pages 免費發布上線

1. 在 GitHub 建立一個名為 `my-portfolio` 或 `<your-username>.github.io` 的公開儲存庫（Public Repository）。
2. 將本專案推送至 GitHub。
3. 進入儲存庫的 **Settings** -> **Pages**。
4. 在 **Build and deployment** 下方的 **Branch** 選擇 `main` 分支並點擊 **Save**。
5. 稍等 1~2 分鐘，即可透過 `https://<your-username>.github.io/<repository-name>/` 隨時隨地向全世界展示您的個人網站！
